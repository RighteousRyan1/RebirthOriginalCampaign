# RebirthOriginalCampaign
Implements the original campaign with all original parameters and mission layouts + randomization.

In order to download and install this mod, do the following:

1. Download the mod source by clicking the green "<> Code" button and clicking "Download ZIP"
2. Navigate to your mods folder (located inside of your game's save directory)
3. Unzip the folder inside of the mods folder

That's all you have to do. From there, you should be able to play the "Original Campaign" campaign listed in your campaigns list.
